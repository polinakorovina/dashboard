# Курсовая работа по созданию дашборда для аналитики дежурств

## Что умеет проект
вообще проект делится на несколько частей, первая это сам дашборд, он умеет: 
- показывать общий обзор по задачам за выбранный период;
- сравнивать текущую и предыдущую недели;
- фильтровать данные по датам, командам, резолюциям и типам;
- импортировать новые данные из файлов;
- экспортировать отчёты в PDF;
  
вторая часть это автоматизация для удобства обращения с дашбордом и в ней реализовано:
- автоматическая отправка свежего отчёта в Telegram по расписанию только определённым подписчикам;
- поддерживать подписку на Telegram-бота через личные чаты и группы.

---
Структура репозитория:

`app.py` – основной файл, он отвечает за отображение дашборда и вся логика для дашборда тоже находится в нём, в том числе расчёты метрик

`data_pipeline.py` – файл для чтения аналитической таблицы из PostgreSQL

`import_utils.py` – модуль для обработки загружаемых файлов. Используется в блоке импорта в app.py: принимает загруженные CSV/XLSX-файлы, очищает и объединяет данные, а затем сохраняет их в базу

`export_utils.py` – файл, содержащий всю логику оформления PDF: шапки страниц, карточки KPI, вставку графиков, настройки шрифтов, стилизацию и сборку итоговых PDF-отчётов для вкладок «Общий обзор» и «Сравнение недель»


`report_payload_builder.py` – файл, который нужен для подготовки данных к экспорту отчётов вне Streamlit. Повторяет ключевую логику дашборда без интерфейса: загружает данные из PostgreSQL, применяет фильтры, собирает метрики и формирует bundle-структуры, которые затем используются в PDF-экспорте.

`report_adapter.py` – файл, который использует report_payload_builder.py и export_utils.py, чтобы собрать готовый PDF-отчёт в памяти без запуска Streamlit-интерфейса. Возвращает итоговый PDF как bytes.

`sync_subscribers.py` – скрипт синхронизации подписчиков Telegram-бота. Получает новые сообщения через Telegram Bot API, обрабатывает команды /start <код> в личных чатах и /register <код> в группах, а затем сохраняет список подписчиков на Яндекс Диск.

`send_weekly_telegram_report.py` – Скрипт еженедельной Telegram-рассылки. Собирает свежий отчёт через report_adapter.py, конвертирует PDF в изображения в памяти, формирует подпись с текстом и ссылкой на дашборд и отправляет отчёт всем подписчикам бота.


`.github/workflows/sync_subscribers.yml` – Workflow для синхронизации подписчиков Telegram-бота.
Запускается по расписанию и вручную. Нужен для того, чтобы без отдельного сервера регулярно забирать новые /start и /register из Telegram.

`.github/workflows/send_weekly_telegram_report.yml` – Workflow для еженедельной отправки отчёта в Telegram. Запускается по расписанию каждый понедельник и вручную. Выполняет сбор свежего отчёта и отправку изображений подписчикам.
